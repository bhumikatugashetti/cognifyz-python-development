🟢 Level 1 Tasks

1. String Reversal

A Python program that takes a string as input and returns the reversed string.

Example:

Input: hello
Output: olleh

2. Temperature Conversion

A program to convert temperatures between Celsius and Fahrenheit.

3. Email Validator

A program that checks whether an email address contains the required email format elements such as "@" and a domain.

4. Calculator Program

A simple calculator that performs:

- Addition "+"
- Subtraction "-"
- Multiplication "*"
- Division "/"
- Modulo "%"

The program also handles division or modulo by zero.

5. Palindrome Checker

A program that checks whether a given word or string reads the same forwards and backwards.

Example:

madam → Palindrome
racecar → Palindrome

🔵 Level 2 Tasks

1. Number Guessing Game

A Python program that generates a random number within a specified range and provides hints such as:

- Too high
- Too low
- Correct

2. Password Strength Checker

A program that evaluates password strength based on:

- Minimum length
- Uppercase letters
- Lowercase letters
- Digits
- Special characters

It displays the result as Weak, Moderate, Strong, or Very Strong.

3. Fibonacci Sequence

A program that generates the Fibonacci sequence for the number of terms entered by the user.

Example:

0 1 1 2 3 5 8 13

4. File Manipulation

A Python program that reads a text file, counts the occurrences of each word, and displays the words alphabetically with their counts.

▶️ How to Run

Make sure Python is installed on your computer.

Open PowerShell or Command Prompt and navigate to the required task folder.

Example:

python calculator.py

For the password checker:

python password_strength_checker.py

For the number guessing game:

python number_guesser.py
